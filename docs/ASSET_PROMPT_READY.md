# Prompts listos para pegar

Cada bloque es un prompt **completo**: el preambulo de estilo y el formato ya
van dentro. Copia uno, pegalo en Google Flow, genera, y guarda el resultado con
el nombre del fichero que figura encima.

Guardalos todos en `public/icons/` salvo los retratos, que van en
`public/portraits/`. Uso esos nombres tal cual para cablearlos, asi que si
cambias alguno, dimelo.

Las tablas de referencia, con el porque de cada decision, estan en
`ASSET_PROMPT.md`. Este fichero sale de ellas: si cambias algo aqui, cambialo
tambien alli.

**47 imagenes**: 5 retratos, 16 iconos de habilidad, 24 de objeto y 2 rotulos.
